# Security Policy

## Supported Scope

Security reports are accepted for all code and metadata published in this repository.

## Reporting a Vulnerability

Please do not open public issues for sensitive vulnerabilities.

Use private disclosure by contacting maintainers through your repository security contact channel.

When reporting, include:

- Affected module(s)
- Impact and severity
- Reproduction steps or proof of concept
- Suggested remediation (if known)

## Response Targets

- Initial acknowledgement: within 5 business days
- Triage and severity assessment: as soon as practical
- Public disclosure: after fix availability and coordinated timeline

## Hardening Expectations

- No committed credentials, keys, or secrets
- Integrity verification via `OPEN_CORE_MANIFEST.sha256`
- Provenance updates for release changes
