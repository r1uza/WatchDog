# Support

## Getting Help

For usage questions and non-security bugs, use GitHub Issues with the provided templates.

## Security Issues

Use the private vulnerability reporting process in `SECURITY.md`.

## What to Include

- Module name
- Expected behavior
- Actual behavior
- Minimal reproduction steps
- Logs or traces (redacted)

## Open Core Boundary Reminder

Requests related to proprietary or enterprise-only features may not be handled in this public repository.
